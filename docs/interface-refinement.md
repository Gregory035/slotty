# Упрощение интерфейса

## Изменения

- Единая палитра и радиусы в `apps/web/src/theme.css` вместо конкурирующих объявлений темы.
- Удалены устаревшие стили лендинга из CSS кабинета: переход между публичной и закрытой частью не должен менять их оформление.
- Первый экран лендинга объясняет продукт текстом и работающим демонстрационным сценарием. Декоративные свечения и чрезмерно крупные заголовки убраны.
- Второстепенные блоки используют разделители вместо одинаковых контейнеров. Фирменный лаймовый акцент оставлен для действий.
- В кабинете уменьшены заголовки и декоративные элементы, на мобильном показатели представлены компактными строками.
- В настройке бизнеса убрана статичная имитация прогресса. На главной панели показаны только незавершённые шаги.
- Статус платной подписки больше не подписывается как пробный период. Изменено только представление, не расчёт подписки.

## Проверка

- Lint, TypeScript, production build: успешно.
- Unit: 110 тестов API и 48 тестов web.
- Браузерные E2E: 8 сценариев в Chromium desktop и WebKit mobile с настоящим локальным API.
- Вручную проверены демонстрация записи, раскрытие FAQ, светлая и тёмная панели, мобильная ширина 440 px без горизонтального скролла.
- Добавлены четыре проверки общей темы, разделения стилей и сохранения доступности.

Проверки выполнены локально на изолированных тестовых данных. Реальные iPhone/Android и production в эту итерацию не входили. Публикация не выполнялась.
