# Permissions

| Возможность | OWNER | ADMIN | EMPLOYEE |
|---|---:|---:|---:|
| Компания: чтение | да | да | да |
| Настройки | да | да | нет |
| Удаление компании | да | нет | нет |
| Участники | полный | только EMPLOYEE | нет |
| Услуги/сотрудники | да | да | нет |
| Расписание | любое | любое | только своё |
| Записи | все | все | только свои |
| Статус записи | любой | любой | только своей |
| Клиенты | да | да | нет |
| Telegram bot | да | да | нет |
| Платежи | да | нет | нет |
| Audit log | полный | без auth/billing/members | нет |
| История записи | да | нет | нет |

Backend является источником истины. Скрытие пункта UI не заменяет permission guard. EMPLOYEE должен быть связан с ровно одним `Employee` внутри компании.
