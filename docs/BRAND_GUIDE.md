# Slotty: расположение логотипов

## Главный логотип продукта

- На компьютере: левый верхний угол боковой панели, один раз на экран.
- На телефоне: левый край верхней панели в компактном формате.
- На входе и регистрации: по центру над формой.
- В онбординге: по центру над карточкой первого шага.
- Внутри рабочих карточек главный логотип не повторяется.

Компонент логотипа находится в `apps/web/src/components/Brand.tsx`. Текущий знак со звездой является временным фирменным знаком; финальный знак можно заменить внутри компонента без изменения экранов.

## Логотип компании

- Показывается отдельно от Slotty в переключателе рабочего пространства.
- Пока используется буквенный аватар из первой буквы названия компании.
- Загруженный логотип компании в будущем заменит только этот аватар.

## Логотипы интеграций

- Логотип Telegram используется только на экране Telegram-бота и в карточке подключения на обзоре.
- Логотип интеграции не должен конкурировать по размеру с главным логотипом Slotty.
- Цвет интеграции допускается только внутри её блока; остальной интерфейс остаётся нейтральным.

## Безопасная зона и размеры

- Основной знак: 32 × 32 px, отступ от краёв не меньше 16 px.
- Компактный знак: 28 × 28 px.
- Рядом со знаком используется только слово `Slotty`; дополнительные подписи размещаются отдельной строкой.
